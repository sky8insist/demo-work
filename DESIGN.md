# Last30 Design System

## Direction

夜航交接日志。界面像一次夜班交接：仍在线的琥珀信号、深海军蓝环境、骨白记录纸和有秩序的日志行。用户不是在管理任务，而是在把今天交出去。

## Visual Language

- Ground: `#081117`; text: `#E9ECE8`; signal: `#FFB64D`; paper: `#D9DDD6`.
- Display type uses condensed lettering; Chinese body copy uses a neutral sans stack.
- Structure comes from ruled rows and handover states, not generic dashboard cards.
- One primary action per stage. Secondary actions are quiet text controls.

## Motion

Stage changes use a short upward settle. Wind-down progressively lowers ambient light, signal color, copy, and control contrast. Reduced-motion removes entrance travel while preserving state clarity.

## Responsive

The product is mobile-first. On narrow screens, headings tighten, footer metadata disappears, input fills the available width, and the countdown becomes viewport-scaled.

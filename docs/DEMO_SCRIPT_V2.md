# Last30 V2 Demo Script

## Flow A — Day Closure

1. 首页说明两条路径：事情需要行动，情绪只需要表达。
2. 选择“收尾今天的事情”，点击“填入演示内容”。
3. 点击“整理今天”，展示完成、明天、等待、释放四类结果。
4. 指出“登录还有问题”获得可编辑的明天第一步。
5. 对“老师邮件还没回”选择“等待后续”，展示 AI 不替用户猜。
6. 选择 08:00，点击“一键结束今天”。
7. 进入 Wind Down，快速记录一件新想法，再跳过倒计时。
8. 点击“演示第二天早晨”，验证 Tomorrow Desk 只承接昨晚明确留下的内容。

## Flow B — Emotion Bottle

1. 重置，选择“打开情绪宣泄瓶”。
2. 强调“今晚只接住，不分析、不建议”。
3. 使用文字演示内容，或切换语音展示波形与录音完成状态。
4. 选择“明天让我看看”，说明原始录音不保存。
5. 跳过 Wind Down，进入第二天，打开已就绪的情绪瓶。
6. 展示事实主题与简短总结；没有诊断、评分或默认建议。

## Demo Safety

- 所有 AI、转写、提醒与跨天行为均为本地演示。
- 麦克风拒绝或不支持时会提供文字回退。
- 浏览器刷新后从 `last30_session_v2` 恢复。
